# QuizPop!

QuizPop is a trivia game I made using Python! It has questions about sports, geography, government, world cultures, and other random facts. Each round gives you 5 questions, and you can share your score with friends to see who does better!

## Features

- 5 random multiple choice questions
- Score tracking and results chart
- Share scores with friends
- Play as many rounds as you want!

## How to Play

1. Click **Code → Download ZIP** and unzip the folder.
2. Make sure you have Python 3 installed.
3. Open Terminal in the folder and run:

```bash
python3 main.py
```
